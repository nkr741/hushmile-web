Hushmile privacy policy

Last updated 22 October 2026. Applies to the Hushmile Android app (app.hushmile.journey) and this web viewer.

In short

Hushmile lets a driver share one road trip with family. There is no account and no Hushmile server. Journey updates are encrypted on the driver's phone with a key made from the Journey Code, and only someone with that code can read them. We (the developer) cannot read them.

What the app uses

  • Precise location, only after the driver starts a journey and while it runs (shown by an ongoing notification). It stops when the journey ends or the code expires (18 hours).
  • The name the driver types, the start and destination they choose, vehicle type, planned route, battery level, stops, kilometres covered and left, and check-in answers (All fine, Break, Traffic, Need help).
  • The family phone sends only "seen" and "please check in" signals, also encrypted.

We do not use advertising, analytics, crash reporting, contacts, phone numbers, photos or device identifiers.

Who can see a journey

Anyone the driver gives the Journey Code to. They see the exact position on a map, its latitude and longitude, the nearest place name, battery level, stops, time and distance left, and the last update time. Share the code only with people you trust.

Services the app talks to

  • ntfy.sh (public message relay) carries the encrypted updates. It keeps each sealed message for about 12 hours and cannot read it. It sees the time and the phone's internet (IP) address.
  • OpenStreetMap services (Nominatim and Photon for place search and place names, OSRM for driving routes and time, Overpass for nearby hospitals and fuel when Need help is used, and OpenStreetMap map tiles). These receive the place you type or a position, over HTTPS, without your name or code, under their own privacy policies.
  • If the driver chooses to text someone or call for help, the phone's own SMS or dialler app is used.

This web viewer

The viewer page is static and hosted on GitHub Pages. The Journey Code stays in the link after the #, which browsers do not send to the web server. The page decrypts updates in your browser and only connects to ntfy.sh. GitHub may log basic request data (such as IP address) under its own policy.

Keeping and deleting data

Journey details on the phone are kept only for the current journey and the last arrival screen. Ending a journey sends a "closed" notice so the code stops opening it, and relay copies expire after about 12 hours. Uninstalling the app or clearing its storage deletes everything on the phone. Because there is no account or server, there is nothing else for us to delete; contact us if you have a question.

Children

Hushmile is meant for adults aged 18 and over.

Not an emergency service

Hushmile does not contact emergency services. In an emergency call 112 (India) or your local number.
